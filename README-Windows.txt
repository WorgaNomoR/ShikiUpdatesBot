ShikiUpdatesBot — portable-версия для Windows 10/11 x64
========================================================

ПЕРВЫЙ ЗАПУСК

1. Полностью распакуйте ZIP в доступную для записи папку, например:
   C:\Users\ВашеИмя\Documents\ShikiUpdatesBot
   Не запускайте exe прямо из ZIP и не кладите папку в Program Files.
2. Запустите ShikiUpdatesBot.exe. Он создаст .env из .env.example и остановится.
3. Откройте .env в Блокноте и заполните BOT_TOKEN, OWNER_ID и SHIKI_USER.
4. Снова запустите ShikiUpdatesBot.exe и не закрывайте консоль во время работы.

Все постоянные файлы остаются в этой папке:
- .env — секретные настройки; никому не передавайте BOT_TOKEN;
- data\ — состояние, подписчики и статистика;
- logs\ — ограниченные по размеру диагностические логи.

ПРОВЕРКА И ОБНОВЛЕНИЕ

- ShikiUpdatesBot.exe --check-config  проверяет настройки без подключения бота.
- ShikiUpdatesBot.exe --version       показывает установленную версию.
- /version в Telegram проверяет последнюю опубликованную сборку (только владелец).
- Для обновления остановите бот и замените только ShikiUpdatesBot.exe.
  Не удаляйте .env, data\ и logs\.

ОСТАНОВКА И БЭКАП

Останавливайте бот через Ctrl+C или закрытием окна. Portable EXE намеренно не
отправляет бэкап при каждом завершении: событийные и еженедельные Telegram-бэкапы
продолжают работать. Команда /backup остаётся основным способом ручного экспорта
состояния.

ВАЖНО

- Бот работает, только пока компьютер включён, не спит и окно exe открыто.
- Неподписанная сборка может вызвать предупреждение SmartScreen/антивируса.
- Запуск от администратора не требуется и не рекомендуется.
- PyInstaller временно распаковывает внутренние файлы в %TEMP%\_MEI... и обычно
  удаляет их после выхода; аварийно убитый процесс иногда оставляет этот каталог.
